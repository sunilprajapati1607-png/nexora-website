GSM to GPM & GPM to GSM calculator

GPM is the weight of one running metre of fabric — the number the loom operator and the roll weighing scale actually see. It equals GSM multiplied by the fabric width in metres; for tubular fabric the width counts twice.

GPM → GSM

Fabric GSM0g/m²

No mesh or denier here. GPM depends only on the fabric GSM and the fabric width. Mesh and denier decide the GSM itself — use the denier to GSM or denier to GPM tool for that.

GSM to GPM formula

GPM = GSM × fabric width (m)  ·  tubular fabric: width (m) = 2 × flat width
GSM = GPM ÷ fabric width (m)
Roll weight (kg) = GPM × roll length (m) ÷ 1000

Example: 80 GSM tubular fabric, 50 cm flat width. Fabric width = 2 × 0.50 = 1.00 m, so GPM = 80 g/m. A 1,000 m roll weighs 80 kg. The same 80 GSM as 50 cm flat (open) fabric is 40 g/m.

Plants use GPM to check looms in real time: weigh a metre of tube, compare with the target GPM, and adjust mesh or tape denier before a whole roll runs heavy. Nexora reports both unlaminated GPM and laminated GPM for every calculation, so lamination lines have a target too.

FAQ

Is GPM the same as grams per metre of tape?

No. Fabric GPM is grams per running metre of fabric. Tape g/m is denier ÷ 9,000 (900 denier = 0.1 g/m). See the denier to GPM page for both.

Why does tubular fabric count the width twice?

A circular loom weaves a tube; one running metre contains two layers of the flat width, so the fabric area per metre is 2 × flat width.

How do I get roll weight from GSM?

Roll weight = GSM × width (m) × length (m) ÷ 1000. The GSM → GPM tool above does it with the optional roll length field.
